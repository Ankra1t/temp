Структура проекта состоит из моделей (models), сообщений и кнопок (message, keyboards), обработчиков (handlers, callbacks), состояния (states). Это основные блоки архитектуры, где расположены вся логика.

Pages - условные основные страницы бота, откуда стартует та или иная логика.
Service - сервисы работы с api.
Common - базовые функции и прочие утилиты.
CHANNEL - класс по работе с каналом, в нём расписаны методы отправки статистики, расчёта, мнения
